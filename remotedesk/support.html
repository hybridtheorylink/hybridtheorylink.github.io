RemoteDesk Support

Last updated: August 22, 2026

RemoteDesk provides direct, low-latency control of a Mac from iPhone, iPad, or another Mac.

Contact

Email hswillg@gmail.com. Include the app version, device models, OS versions, and a short description of the issue.

Requirements

  • Mac Host: macOS 14 or later
  • iPhone or iPad Client: iOS/iPadOS 18 or later
  • Both devices must have a direct network path to each other
  • The Mac Host needs Screen Recording and Accessibility permission

Quick Start

  1. Open RemoteDesk on the Mac to control and select Host.
  2. Select a display, allow the requested permissions, and start the Host.
  3. Open RemoteDesk on the controlling device and add a connection.
  4. Select the Mac under Nearby Macs or enter its address and base port.
  5. Enter the pairing code shown on the Host, then connect.

Troubleshooting

The Mac does not appear under Nearby Macs

Confirm both devices are on the same local network and Local Network access is enabled for RemoteDesk. You can also enter the Host address shown in Connection Details.

The connection fails

Check the address, pairing code, and base port. RemoteDesk uses UDP on the base port and TCP on base port + 1. Firewalls or routers must allow both. Remote access outside the local network requires your own VPN or port-forwarding setup.

The screen is black or input does not work

On the Host Mac, open System Settings → Privacy & Security. Enable Screen Recording for video and Accessibility for mouse and keyboard control, then restart RemoteDesk if macOS requests it.

The Host identity changed

RemoteDesk pins the Host certificate after pairing. If the Host was reinstalled or reset, delete the saved connection on the Client and pair again only after confirming the Host is trusted.

Purchase is missing

Open the Pro screen and choose Restore Purchases. Confirm the device uses the Apple Account that made the purchase. Monthly and yearly plans can be managed in Apple Account subscription settings.
