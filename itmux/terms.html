App Description

iTmux is an SSH and tmux workspace for iPhone, iPad, and Mac. It lets you connect to your own servers over SSH, attach to persistent tmux sessions, windows, and panes, browse, edit, and transfer remote files, work with Git repositories, keep host-side notes, and follow AI coding tasks (such as Claude Code and Codex) that run on your own hosts.
