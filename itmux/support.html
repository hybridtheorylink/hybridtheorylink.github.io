App Overview

itmux is an SSH and tmux terminal client for iPhone, iPad, and Mac. Connect to your servers over SSH, attach to real tmux sessions that keep running when you disconnect, manage windows and panes, edit remote files, and view remote screens over VNC.

Key Features

  • SSH connections with password, on-device SSH key, or agent authentication
  • Native tmux control-mode integration — real sessions, windows, and panes
  • Fast, full-color terminal with a touch-friendly key bar
  • Tabbed sessions, with tear-off windows on Mac
  • Remote file browser and built-in file editor
  • Host-side notes kept with your server
  • Built-in VNC viewer in a standalone window
  • Voice dictation of commands (iOS)
  • 14 interface languages

Getting Started

  • Open the app and add a connection with your host, port, and username.
  • Choose password or SSH key authentication. For key auth, copy the app’s public key from Settings → SSH Key into your server’s ~/.ssh/authorized_keys.
  • Connect. If tmux is installed on the server, itmux attaches to (or creates) a session automatically.

Troubleshooting

  • Can’t connect: Verify the host, port, and that the server is reachable and the SSH service is running.
  • Key auth rejected: Confirm the public key from Settings → SSH Key is installed in ~/.ssh/authorized_keys with the correct permissions.
  • tmux not attaching: Ensure tmux is installed on the server and available in your shell’s PATH.
  • Dictation not working: Allow Microphone and Speech Recognition access for itmux in iOS Settings.
