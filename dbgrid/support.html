App Overview

DBGrid is a native macOS client for MySQL and Oracle. Browse schemas, write SQL with schema-aware completion, edit data right in the grid, design tables visually and keep production databases safe. The database engine is bundled with the app — there is no Java to install.

Key Features

  • Connection tree with schemas, tables, views, procedures, columns, indexes and triggers; instant filter across thousands of tables
  • SQL editor with syntax highlighting, completion, formatting and ⌘↩ to run the current statement, a selection or the whole script
  • Oracle PL/SQL blocks and DBMS_OUTPUT; MySQL DELIMITER support
  • Edit cells, add and delete rows in the grid; preview the SQL, then Apply or Revert
  • Visual table designer for fields, indexes and options, with the generated DDL shown before it runs
  • Saved queries with folders and notes, full SQL history, export to CSV, JSON, SQL and text
  • DEV / STAGING / PROD color tags; production connections open read-only and ask before any write
  • SSH tunnels and SSL/TLS; passwords stored only in the macOS Keychain

Frequently Asked Questions

Which databases are supported?

MySQL and Oracle Database (connecting by service name or SID).

What does DBGrid Pro add?

The free version saves one connection. DBGrid Pro is a one-time purchase that unlocks unlimited connections on every Mac signed in with your Apple Account. There is no subscription. Use “Restore Purchases” in the upgrade window to unlock Pro on another Mac.

Where are my passwords stored?

Only in your macOS Keychain. Connection settings, query history and saved queries stay on your Mac. DBGrid has no account and sends no analytics.

How do I connect through an SSH tunnel?

Open the connection, switch to the SSH tab, enable the tunnel and enter the SSH host, user and either a password or a private key file. DBGrid connects to the database through the tunnel.

Troubleshooting

  • Connection times out: check the host, port and firewall rules, or raise the connect timeout in the connection's Advanced tab.
  • Oracle ORA-28009 when logging in as SYS: choose the SYSDBA role in the connection dialog.
  • A table cannot be edited: editing in the grid needs a primary or unique key so every change targets exactly one row.
  • Writes are blocked on a connection: production connections start as read-only sessions — turn off “Read-only session” in the red banner to write.
